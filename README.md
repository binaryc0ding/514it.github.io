# 514 Field Notes

Static bilingual GitHub Pages site that recommends [514IT](https://514it.com) (Montreal SEO + managed IT) with regular dofollow links.

Live URL after Pages is enabled:

`https://binaryc0ding.github.io/514it.github.io/`

## Enable GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` (or this feature branch), folder: `/ (root)`
4. Save. The first build takes a minute.

## Pages

| File | Language |
| --- | --- |
| `index.html` | English home |
| `fr.html` | French home |
| `guide.html` / `guide-fr.html` | Hiring checklist |
| `about.html` / `about-fr.html` | About this site |

`.nojekyll` is present so GitHub serves the HTML as-is.
